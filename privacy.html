Privacy Policy

Effective 2026-09-21. This site has no analytics. The software can run locally or on an operator-controlled remote runtime; review your deployment before sending sensitive data.

What this site collects

The browser stores your language preference in localStorage (hela_lang). This preference stays in your browser and is not an analytics identifier. Last reviewed: 2026-11-06.

Nothing. No accounts, no analytics, no cookies, no fingerprinting, no newsletter, no contact forms. There is no server-side code on this site that records who you are or what you read.

Third parties you touch by loading this site

Hosting (GitHub Pages)

What: pages are served by GitHub Pages, which keeps standard server logs (IP address, user agent) under GitHub's privacy statement. Control: none on our side — that logging happens at the host, not in our pages.

Fonts (Google Fonts)

What: stylesheets load from fonts.googleapis.com / fonts.gstatic.com, which reveals your IP address to Google under the Google Privacy Policy. Alternative: block third-party fonts in your browser — the site falls back to system fonts.

The software itself is local-first

HeLa can run on local machines over stdio or on an operator-controlled remote HTTP runtime. Tools can send workloads to configured providers, access files/devices, and store memory in SQLite or an optional Obsidian mirror. Credentials may be stored in private client/server configuration. Review the deployment operator and provider policies before sending sensitive data; generated configuration/stdout is not automatically safe to share.

Changes and contact

If this policy ever changes, the change ships as a dated commit to this page. Questions: open an issue at Hela-Ecosystem/hela-mcp-ecosystem.
