SPEC_07 // Hela-Ecosystem-MCPDOSIR: KEBIJAKAN_PRIVASI

Kebijakan Privasi

Berlaku sejak 2026-09-21. Situs ini tidak memakai analitik. Perangkat lunak dapat berjalan lokal atau pada runtime jarak jauh pilihan operator; tinjau kebijakan deployment sebelum mengirim data sensitif.

Apa yang dikumpulkan situs ini

Browser menyimpan pilihan bahasa di localStorage (hela_lang). Preferensi ini tetap berada di browser dan bukan pengenal analitik. Terakhir ditinjau: 2026-11-06.

Sama sekali tidak ada. Tanpa akun pengguna, tanpa pelacak analitik, tanpa cookie, tanpa teknik fingerprinting, tanpa buletin berkala, dan tanpa formulir kontak. Tidak ada kode pemrosesan sisi server (server-side) pada situs dokumentasi ini yang mencatat identitas Anda atau konten apa yang Anda telusuri.

Layanan pihak ketiga saat memuat situs

Penyedia Hosting (GitHub Pages)

Cakupan: Halaman web ini dilayani oleh infrastruktur GitHub Pages, yang menyimpan log server standar (alamat IP pengakses, user-agent) berdasarkan Pernyataan Privasi GitHub. Kontrol: Kami tidak memiliki akses atau kendali terhadap pencatatan log tingkat hosting tersebut.

Penyedia Font (Google Fonts)

Cakupan: Lembar gaya font dimuat secara eksternal melalui fonts.googleapis.com / fonts.gstatic.com, yang memperlihatkan alamat IP Anda kepada Google sesuai dengan Kebijakan Privasi Google. Alternatif: Anda dapat memblokir pemuatan font pihak ketiga pada browser Anda — situs secara otomatis beralih menggunakan font bawaan sistem Anda tanpa kendala fungsionalitas.

Perangkat lunak berarsitektur local-first

HeLa dapat berjalan lokal melalui stdio atau melalui runtime HTTP jarak jauh yang dikelola operator. Alat dapat mengirim pekerjaan ke provider terkonfigurasi, mengakses berkas/perangkat, serta menyimpan memori di SQLite atau mirror Obsidian opsional. Kredensial dapat tersimpan pada konfigurasi privat klien/server. Tinjau operator deployment dan kebijakan provider sebelum mengirim data sensitif; hasil generator konfigurasi/stdout tidak otomatis aman untuk dibagikan.

Pembaruan kebijakan & kontak

Apabila kebijakan ini diperbarui di masa mendatang, perubahan akan dicatat sebagai commit bertanggal resmi pada halaman ini. Pertanyaan atau masukan: silakan buka tiket issue di Hela-Ecosystem/hela-mcp-ecosystem.
