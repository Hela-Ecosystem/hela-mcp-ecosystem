SPEC_02 // Hela-Ecosystem-MCPDOSIR: TOPOLOGI_DUAL_BACKBONE

Arsitektur Ekosistem

Dua backbone mengoordinasikan sepuluh sel: Mitosis merencanakan dan merutekan tugas; Genome menyimpan memori persisten. Sel lain mengelola status domainnya, termasuk sesi browser dan terminal. Hubungkan secara terpisah melalui stdio atau lewat runtime opsional.

Dual Backbone

TABEL 2.1 — PEMBAGIAN TANGGUNG JAWAB BACKBONE
BackboneMenangani & MemilikiTidak Pernah Menangani
Mitosis (hela-mitosis)Penalaran bertahap, dekomposisi tugas, perutean rantai alat, template promptStatus persisten
Genome (hela-genome)Grafik pengetahuan SQLite, entitas/relasi, konteks sesi, sinkronisasi sentralKeputusan eksekusi

Aturan interaksi: agen berpikir melalui Mitosis, menyimpan memori melalui Genome, dan bertindak melalui sel-sel lainnya. Sinergi terverifikasi (lihat npm test): Mitosis+Genome (backbone), Enzyme+Cytosol (riset), Membrane+Nucleus+Ribosome (workspace).

Transport Komunikasi

Klien standalone menjalankan sel melalui MCP stdio menggunakan path inventori. Runtime opsional juga mendukung Streamable HTTP. Pilihan transport tidak mencegah alat mengakses jaringan atau mengubah sumber daya host. Autentikasi dan otorisasi endpoint masih ditunda; pemisahan proses bukan sandbox OS.

Referensi Server & Organel

Sepuluh sel. Cakupan CORE berjalan murni headless; SPECIALIZED membutuhkan GUI, emulator perangkat, atau dependensi runtime khusus.
